# Space Compute Assets

This directory contains the production vector assets and design reference styles for Space Compute.

For detailed developer instructions, React 19 + TypeScript component code snippets, and integration mappings, see:
👉 **[`ASSET_INTEGRATION_GUIDE.md`](./ASSET_INTEGRATION_GUIDE.md)**

### Subdirectories:
* **`badges/`**: 10 curated visual badge style assets (`style_01` to `style_10`).
* **`tiers/`**: 5 Tier Insignia SVGs (Stargazer to Principal Investigator).
* **`categories/`**: 8 Discovery Category SVGs (lensed_arc, merger, little_red_dot, etc.).
* **`states/`**: 5 UI Empty, Offline & Error state illustrations.
* **`fuel/`**: 5 Canister fuel cell & treasury runway SVGs.
* **`payments/`**: 6 Payment rail badges (ICP, OISY, BTC, ETH, Card, Invite Code).
* **`brand/`**: App logo (512x512), favicon, and landing page architecture diagram.
