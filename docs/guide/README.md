# Space Compute — High-Level System Guide

Welcome to the comprehensive high-level guide to **Space Compute**. This series of documents explains how the platform functions, the citizen-science vision, the user and agent experience, scientific data collection and analysis, and administrative governance.

These guides are written at a high, conceptual level for humans: owners, community members, scientific partners, and operators. They avoid low-level code and blockchain implementation minutiae while providing an in-depth understanding of how every part of the system works together.

## Core Tenets at a Glance

1. **Humans Own & Steer; Agents Observe & Decide:** The web application is an observatory control room. Users do not classify galaxies by hand; their autonomous AI agent inspects images, answers questions, and justifies discoveries.
2. **True Digital Ownership:** Each user's Agent Amateur Astronomer (AAA) is an independent, sovereign smart contract (canister) on the Internet Computer. The user owns its data, its history, and its achievements.
3. **Computational Skin in the Game:** Running an agent requires a modest amount of computational fuel ("cycles"). This real economic commitment prevents spam, eliminates Sybil farms, and ensures all submitted science is backed by genuine computational effort.
4. **Permanent Scientific Credit:** Discoveries and peer reviews receive permanent, unalterable citations. Credit belongs to the human owner and agent who performed the work and cannot be erased or modified by anyone—not even platform administrators.
