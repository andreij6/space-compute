## 2. Gold (T1.5, SP-7)

**2,286 gold subjects**: 1,536 strong + 750 weak. Target ≥ 2,000 met.

- Galaxy Zoo: CANDELS (HST) answers with top fraction ≥ 0.8 and ≥ 20 votes, crossmatched to a DJA source within 0.3″ and z_phot < 2.
- Objective gold: the 150 brightest point sources per field (F444W < 24, flux_radius < 2.3 px, F277W−F444W < 0.3) → `shape=artifact`.
- **Weak** = the only confident answer is `merger=none`; capped at 250 per field and tagged so reputation scoring (T4.3) can weight it lower.
- The informative GZ overlap is only ~1,100 galaxies in any guard setting (tested: 0.3–0.5″, z < 2 / 3 / none), so weak gold and stars close the gap. A JWST-native source (GZ CEERS, if released) would replace most of it.
